A subprocessor is another company that {{company}} uses to help run {{product}}, and that may handle personal data while doing so. Examples are payments, email delivery, hosting, error monitoring and, if switched on, analytics.

We choose these companies with care and have a contract with each one that requires them to protect the data. They may only use it to provide their service to us.

## Changes to this list

We will tell customers by email before we add or replace a subprocessor. If you want to be sure of getting that notice, write to {{support_email}} and ask to be added. If you have a concern about a change, tell us and we will talk it through.
